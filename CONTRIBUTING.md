# Contributing

Thank you for looking closely. This repository is the public interface to a managed service, so the most useful
contributions are:

- **Claim defects.** A statement here that the live service does not honour. These are treated as bugs, not
  disagreements — use the *Claim defect* issue form.
- **Contract problems.** Something in [`openapi.yaml`](./openapi.yaml), the schemas or the docs that is wrong,
  ambiguous, or missing for a real integration.
- **Example fixes.** Improvements to the curl and Python examples.

Please do **not** report security vulnerabilities in a public issue — see [SECURITY.md](./SECURITY.md).

Pull requests are welcome for documentation and examples. By submitting one you agree that your contribution is
licensed under the [MIT licence](./LICENSE). Changes to the contract itself follow the deployed service: we will
merge them only when the service behaves that way.

For access, pricing or partnership questions, use the links in the README rather than issues.
